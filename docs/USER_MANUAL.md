## 1. 产品概述

Modem Cat 是一款面向 5G 模组的桌面调试工具，提供以下核心能力：

- **模组连接**：支持 USB 串口、TCP 直连、WebSocket 网关三种连接方式，自动识别 Quectel 模组的芯片平台（展锐 UniSoc / 高通 Qualcomm / ASR RedCap）
- **实时状态监控**：SIM 卡、运营商、网络类型、信号质量（RSRP / RSRQ / SINR）、小区参数、流量统计等全部实时读取
- **蜂窝网络配置**：APN 管理、首选网络、频段锁定、PLMN 锁定、小区 / 频点锁定、邻区查看、5GLAN 配置
- **AT 指令调试**：内置终端，可手动发送任意 AT 命令，支持快捷命令与日志导出
- **底层调试通道**：ADB shell（Windows）与 SSH shell，用于模组 Android / Linux 系统的深度调试
- **情景模式**：一键切换路由 / 桥接 / 宽带等工作场景
- **固件下载**：安全刷写展锐 UniSoc 平台模组固件包（PAC 格式），内置射频校准保护
- **多语言 / 多主题**：中 / 英文界面，深色 / 浅色两种主题

## 2. 安装与启动

### 2.1 系统要求

| 平台 | 最低版本 | 必要组件 |
|---|---|---|
| **Windows** | Windows 10 1809+ | WebView2 Runtime（Win10 1803+ / Win11 已内置） |

| **Linux** | 任意现代发行版 | `libgtk-3`、`libwebkit2gtk-4.1`、`libudev1`、`libappindicator3` |

## 3. 连接模组

启动 Modem Cat 后，默认打开模组状态页。顶部「接口配置」面板是连接入口。

### 3.1 连接类型

| 类型 | 适用场景 |
|---|---|
| **USB / TTL Serial** | 使用 USB 直连或 USB 转串口适配器连接模组 |
| **Ethernet TCP** | 模组启用 TCP 服务器，通过以太网直连（WebSocket 网关） |

### 3.2 连接步骤

1. 选择「连接类型」
2. 在「端口 / 地址」下拉框中选择目标端口（USB 模式会自动列出可用串口；TCP 模式需手动填入 `host:port`）
3. 若选择 Ethernet TCP，且网关需要认证，下方会出现「WebSocket 用户名 / 密码」输入框——**请输入网关提供的凭据，不提供时保持匿名**
4. 点击 **「连接」** 按钮

连接成功后：

- 底部「模组」状态变为「已连接」，并显示端口名且亮绿
- 前端自动回读：状态、IP、硬件信息、APN 列表、QoS、流量

### 3.3 自动连接

启用后（默认），若检测到模组串口重新插入（USB 热插拔），Modem Cat 将自动重连。拔出后 2~4 秒内也会自动断开并更新状态。

### 3.4 自动识别芯片平台

连接时最先通过 USB `VID/PID` 判断芯片平台：

| VID / PID | 芯片 |
|---|---|
| `0x2C7C:0x0900` | 展锐 UniSoc（RG200U / RM500U 等） |
| `0x2C7C:0x0800` / `0x0801` | 高通 Qualcomm（RM500Q / RM520N 等） |
| `0x2C7C:0x0600` | ASR RedCap（RG255AA 等） |
| `0x2C7C:0x600C` | ASR RedCap（`0x0600` 的 ADB-on 变体） |

若无法枚举到 USB ID，Modem Cat 自动回退 `AT+CGMM` 型号匹配。识别失败时页面会提示"不支持的模组"。

## 5. 模组状态页（首页）

模组状态页是连接成功后默认打开的首页，分为 **「网络状态」** 和 **「IP 信息」** 两个子 Tab。

### 5.1 网络状态 Tab

以信息卡片矩阵展示所有实时状态，每条数据都通过 AT 命令实时读取。点击右上角 **「刷新」** 按钮手动回读。

| 参数 | 说明 | 来源 |
|---|---|---|
| **SIM 状态** | READY / NO SIM / SIM PIN / UNKNOWN | `AT+CPIN?` |
| **注册状态** | 是否注册到运营商网络 | 服务小区解析 |
| **连接状态** | 数据通道是否激活（PDP） | `AT+CGACT?`（UniSoc） / `AT+QMAP="MPDN_status"`（Qualcomm） |
| **IMEI** | 设备国际移动设备识别码 | `AT+CGSN` |
| **ICCID** | SIM 卡集成电路卡识别码（SIM 未就绪显示 `--`） | `AT+CCID` / `AT+ICCID` |
| **运营商** | 当前注册运营商名称 | `AT+COPS?` |
| **网络类型** | LTE / NR5G-SA / NR5G-NSA / WCDMA 等 | 服务小区解析 |
| **PCI** | 物理小区 ID | 服务小区 |
| **Cell ID** | 小区唯一标识 | 服务小区 |
| **ARFCN** | 频点号（LTE EARFCN / NR-ARFCN） | 服务小区 |
| **Band** | 当前工作频段（如 n78 / B1） | 服务小区 |
| **频宽** | 载波带宽（MHz） | 服务小区 |
| **RSRP** | 参考信号接收功率（dBm），越大越好 | 服务小区 |
| **RSRQ** | 参考信号接收质量（dB），越大越好 | 服务小区 |
| **SINR** | 信号与干扰加噪声比（dB），越大越好 | 服务小区 |
| **TX Power** | 发射功率（dBm） | 服务小区 |
| **RX Level** | 接收电平 | 服务小区 |
| **CQI** | 信道质量指示 | QoS |
| **SCS** | 子载波间隔（kHz）：15 / 30 / 60 / 120 / 240 | 服务小区 |
| **ANT 0 ~ 3** | 4 根天线的 RSRP 分量 | `AT+QRSRP?`（Qual） / `AT+QANTRSSI?`（UniSoc） |
| **签约上行带宽** | 运营商签约的上行最大带宽 | QoS |
| **签约下行带宽** | 运营商签约的下行最大带宽 | QoS |
| **上行流量** | 累计发送字节数 | `AT+QGDCNT?` / `AT+QGDNRCNT?` |
| **下行流量** | 累计接收字节数 | 同上 |

### 5.2 SIM 卡槽切换

SIM 状态卡右上角有 SIM 卡槽指示器（"SIM 1" 或 "SIM 2"），点击可展开下拉切换。切换后会自动重新读取模组状态。**注：仅支持双卡槽模组。**

### 5.3 IP 信息 Tab

展示模组的 IP 层网络参数（点击 IPv4 旁的刷新图标手动回读）：

- **IPv4 地址 / 子网掩码 / 网关 / DNS**
- **IPv6 地址 / DNS**

> UniSoc 通过 `AT+QNETDEVSTATUS=<cid>` 读取；Qualcomm 通过 `AT+QMAP="WWAN"` 读取。

### 5.4 底部快捷开关

状态页底部状态栏（详见 [状态栏说明](#18-状态栏说明)）：

- **射频开关**：切换模组射频功能开 / 关（AT+CFUN 0/1）
- **数据连接按钮**：手动拨号 / 断开（仅在已连接状态且未激活数据时显示「连接」）

## 6. 在线监控页

对信号质量进行**连续轮询 + 图表化显示**，适合外场路测、信号稳定性观测等场景。

### 6.1 控制项

| 控件 | 说明 |
|---|---|
| **刷新间隔** | 可选 5s / 10s（默认）/ 15s / 30s |
| **监控开关** | 启用 / 禁用自动轮询 |
| **RSRP 数值徽章** | 当前 RSRP 实时显示 |
| **SINR 数值徽章** | 当前 SINR 实时显示 |

### 6.2 图表

- **RSRP 信号强度曲线**：随时间变化绘制，便于观察信号波动
- **SINR 信噪比曲线**：随时间变化

> 启用监控开关后，界面顶部徽章和图表会自动按刷新间隔更新。关闭页或关闭开关即停止轮询。

## 7. 蜂窝网络页

蜂窝网络页包含 **5 个子 Tab**，从左到右依次是：APN 配置、网络配置、小区 / 频点锁定、邻区信息、5GLAN。

### 7.1 APN 配置

APN（接入点名称）是模组连接运营商数据网络的基础配置。

**界面元素**：

- APN 列表页：显示当前所有 APN，每条显示 CID、APN 名称、鉴权类型、IP 类型
- 每条 APN 右侧有「激活 / 停用」开关
- 右上角 **「新增 APN」** 按钮打开配置弹窗

**操作说明**：

| 操作 | 说明 |
|---|---|
| **新增 APN** | 点击「新增 APN」→ 在弹窗填写 CID、APN 名称、用户名、密码、鉴权类型（None / PAP / CHAP）、IP 类型（IPv4 / IPv6 / IPv4v6 / Ethernet）→ 保存 |
| **编辑 APN** | 点击 APN 条目可回填信息到弹窗修改 |
| **删除 APN** | 点击 APN 条目旁的删除按钮 |
| **激活 / 停用** | 切换 APN 的活动状态（`AT+CGACT`） |

> APN 配置通过 `AT+QICSGP` 完整下发，用户名 / 密码为可选字段；未提供时不会补默认值。

### 7.2 网络配置

#### 7.2.1 首选网络

从下拉框选择：

| 选项 | 含义 |
|---|---|
| 自动 | 模组自动选择可用网络类型 |
| 仅 5G | 强制 NR5G 模式 |
| 仅 LTE | 强制 LTE 模式 |

选择后点击 **「保存」** 下发。

#### 7.2.2 IMS（VoLTE）

通过「开启 / 关闭」按钮切换 IMS 状态。开启后模组支持基于 LTE 的语音通话。

#### 7.2.3 频段设置

频段网格展示 LTE 与 NR 两个分组，每个频段号对应一个可点击的复选框。

- 频段来源：`AT+QNWPREFCFG=?` 读取模组支持的频段列表
- 已锁定频段高亮显示
- 点击频段卡切换锁定状态，支持多选
- 点击 **「保存」** 下发锁定，**「重置」** 恢复全频段

> LTE 频段：B1 / B3 / B5 / B7 / B8 / B20 / B28 / B38 / B39 / B40 / B41 / B42 / B43 等
> NR 频段：n1 / n3 / n5 / n7 / n8 / n20 / n28 / n38 / n40 / n41 / n77 / n78 / n79 等

#### 7.2.4 PLMN 锁定

PLMN（公共陆地移动网络）锁定用于将模组固定到指定运营商。

- **MCC**：移动国家码（如 460 = 中国）
- **MNC**：移动网络码（如 00 = 中国移动，01 = 中国联通）
- **锁定密码**：供应商提供的 PLMN 锁定密码（必填，不提供无法锁定）

点击 **「锁定」** 应用，**「解锁」** 清除。

> ⚠️ 锁定密码必须向模组供应商获取，没有通用默认值。

### 7.3 小区 / 频点锁定

用于将模组锁定到指定的频点或具体小区，常用于网络优化测试。

| 字段 | 说明 |
|---|---|
| **频点** | EARFCN（LTE）或 NR-ARFCN（5G），如 `504990` |
| **PCI** | 物理小区 ID（可选，不填则只锁频点） |
| **SCS** | 子载波间隔（Qualcomm 显示）：15 / 30 / 60 / 120 / 240 kHz |
| **Band** | 频段号（Qualcomm 显示），如 `41` |

- **保存**：写入锁定配置
- **清除锁定**：解除当前所有小区 / 频点锁定

页面顶部「当前锁定」提示区域会显示已锁定的目标参数。

### 7.4 邻区信息

展示当前服务小区的**邻区分 LTE / NR 两个子 Tab**：

**LTE 邻区列**：PCI / RSRP / RSRQ / EARFCN

**NR 邻区列**：PCI / RSRP / RSRQ / SINR / NR-ARFCN

点击 **「刷新」** 按钮重新从模组拉取邻区列表。无数据显示「暂无数据」。

### 7.5 5GLAN

5GLAN 页分为 **「展锐 UniSoc」** 和 **「高通 Qualcomm」** 两个子 Tab。

#### 7.5.1 UniSoc（一步完成）

| 字段 | 说明 |
|---|---|
| CID | 数据连接通道号（1 ~ 15） |
| VLAN ID | VLAN 标识（1 ~ 255） |
| 启用开关 | 开启 / 关闭此 5GLAN 通道 |

点击 **「保存」** 下发到模组。

#### 7.5.2 Qualcomm（3 步顺序操作）

> ⚠️ Qualcomm 5GLAN 分 3 步且中间需要重启，请按指引顺序操作。

**步骤 1 — 配置接口参数**

| 字段 | 说明 |
|---|---|
| PHY Profile | PHY 配置 ID（1 ~ 4） |
| CID | 通道号（1 ~ 15） |
| APN | 接入点名，如 `5glan2` |
| S-NSSAI | 切片标识（可选），如 `03.010102` |
| 使用 VLAN ID 范围 | 勾选后显示 VLAN 起始 / 结束输入框 |

点击 **「配置参数」** 下发。

**步骤 2 — 启用 ETH PDU 会话**

> ⚠ 启用后需**重启模组**，重启完成后再继续步骤 3。

点击 **「启用 ETH PDU」** 按钮。

**步骤 3 — MPDN 规则 & 连接（重启后）**

| 字段 | 说明 |
|---|---|
| Rule ID | MPDN 规则号（0 ~ 7） |

点击 **「设置规则并连接」** 完成。

**状态区**：底部「当前状态」可点击「刷新」按钮查看 MPDN 当前连接状态。

## 8. IP 配置页

IP 配置页分为 4 个功能区块，部分仅显示在对应的芯片平台下。

### 8.1 LAN IP 配置

设置模组的局域网网关参数。

| 字段 | 说明 |
|---|---|
| 网关 IP | 模组的局域网网关地址，如 `192.168.100.1` |
| 子网掩码 | 如 `255.255.255.0` |
| DHCP 起始 / 结束 | 模组 DHCP 地址池的首 / 末地址 |

点击右上角加载图标回读当前配置；点击 **「保存」** 下发。ASR 平台下拉后需重启生效。

### 8.2 MTU 配置

设置数据通道的 MTU（最大传输单元）。

| 参数 | 范围 | 推荐值 |
|---|---|---|
| MTU 值 | 576 ~ 9000 | 1500（以太网） / 1480（PPPoE） / 1400（VPN） |

点击 **「应用」** 下发。

### 8.3 DMZ 配置

将指定内网 IP 设为 DMZ 主机，该主机会接收所有未映射的入站流量。

- 填入 DMZ 主机 IP 后点击 **「应用」** 启用
- 点击 **「清除」** 关闭

> ⚠ 启用 DMZ 后该主机将完全暴露在公网流量下，请确保主机有安全防护。

### 8.4 VLAN 配置

**仅 Qualcomm 模组支持。**

- 启用开关 / 禁用开关
- 启用后可填写 VLAN ID（1 ~ 255）并点击 **「应用」**

UniSoc / ASR 模组进入此区域时，VLAN 区块会显示"仅 Qualcomm 模组支持 VLAN 配置"。

## 9. AT 调试页

AT 调试页是高级用户的完整 AT 命令终端，允许直接通过模组 AT 端口发送任意指令。

### 9.1 终端操作

1. 连接模组后，在底部输入框键入 AT 命令（如 `AT+CPIN?`）
2. 按 **Enter** 或点击 **「发送」** 执行
3. 响应实时显示在上方终端区：`OK`（绿色）、`ERROR`（红色）、普通响应（白色）

### 9.2 快捷命令栏

3 排共 15 个高频 AT 快捷按钮，点击即发送：

| 排 | 命令 |
|---|---|
| 第 1 排 | `ATI` / `AT+CPIN?` / `AT+COPS?` / `AT+CGDCONT?` / `AT+CGACT?` |
| 第 2 排 | `AT+QENG="servingcell"` / `AT+QNWPREFCFG="mode_pref"` / `AT+QNWPREFCFG="nr5g_band"` / `AT+QNETDEVSTATUS=1` / `AT+CGPADDR` |
| 第 3 排 | `AT+QICSGP?` / `AT+QMAP="mpdn_rule"` / `AT+QMAP="wwan"` / `AT+QMAP="auto_connect"` / `AT+QMAP="lanip"` |

### 9.3 日志导出

点击 **「导出」** 按钮，弹出系统「另存为」对话框，将当前终端屏幕上显示的响应保存为 `.txt` 文本文件。

### 9.4 清除终端

点击 **「清除」** 按钮清屏，或每次发送新命令时自动匹配。

## 10. ADB 调试页

> **仅 Windows 系统下可用**，需要 Windows 包中已包含 ADB 组件。

ADB 调试页允许在已连接模组的 Windows 主机上启动一个 ADB shell 会话，直接操作模组内部的 Android / Linux 系统。

### 10.1 操作流程

1. 连接模组（USB 串口）
2. 进入 ADB 调试页，点击 **「连接」**
3. 按钮变为 **「断开」**，终端区出现 shell 提示符
4. 点击终端区域后可键盘直接输入命令（Enter 发送）
5. 长按右键可粘贴文本
6. 点击 **「断开」** 关闭会话；离开页面时也会自动断开

### 10.2 清除终端

点击 **「清除」** 清屏。

### 10.3 注意事项

- ADB 调试不经过 AT 端口，它是独立子进程直接 `adb.exe shell`
- 若提示 ADB 未找到，请检查 Windows 包是否包含 `adb.exe` 与相关 DLL
- 模组需启用 ADB 功能（在「模组配置」页 → 功能开关 → ADB 开关）

## 11. SSH 调试页

SSH 调试页通过 SSH2 直连模组的 Linux shell，独立于 AT 通道。

### 11.1 配置项

| 字段 | 说明 |
|---|---|
| **有线网卡** | 下拉框选择本地有线以太网卡（自动枚举） |
| **设备 IP** | 默认填入所选网卡的网关地址，可手动修改 |

1. 连接模组（USB 串口）

3. 选择有线网卡，设备 IP 自动带出网关
4. 点击 **「连接」**
5. shell 就绪后，点击终端区域输入命令

### 11.3 偏好记忆

Modem Cat 会自动保存：**用户名 / 上次网卡 / 上次 IP**。密码为每次连接强制输入，不写入存储。

### 11.4 断开与会话

- 点击 **「断开」** 关闭当前 SSH 通道
- 离开页面自动断开
- 点击 **「清除」** 清屏

> **当前仅展锐 UniSoc 平台可用**，高通平台显示「即将推出」。

### 12.1 内置 UniSoc 场景

## 13. 固件下载页

固件下载页负责安全刷写 Quectel 模组的 `.pac` 格式固件包。

### 13.1 操作流程

**Step 1：选择 PAC 文件**

点击 **「选择 PAC」** → 在系统文件对话框选中 `.pac` 文件 → Modem Cat 自动调用后端分析固件包。

**Step 2：安全策略检查**

分析完成后，「安全策略状态」区域会显示固件包内容分类：

- ✅ 含射频校准 → **禁止刷写**（红色）
- ✅ 含 NV 擦写 → 需确认后继续
- ✅ 含 Erase → 需确认后继续
- ✅ 纯下载 → 允许

风险等级划分在页面上以彩色标签展示。

**Step 3：开始下载**

安全策略校验通过后 **「开始下载」** 按钮启用，点击开始。

**Step 4：观察进度与日志**

- 顶部实时进度条显示当前刷写百分比
- 底部「系统运行日志」控制台显示详细操作日志

**Step 5：停止（可选）**

点击 **「停止」** 按钮可中止正在进行的固件下载。

### 13.2 固件下载事件

| 事件类型 | UI 反应 |
|---|---|
| Log | 追加一行到日志控制台 |
| Progress | 更新进度条百分比 |
| PacLoadProgress | 显示 PAC 加载进度 |
| StateChange | 记录状态转换 |
| Completed（成功） | 进度条变绿，显示成功 |
| Completed（失败） | 进度条变红，显示错误 |
| Error | 进度条变红，终止流程 |
| Terminated | 异常退出或手动停止 |

### 13.3 安全保护

- **射频校准保护**：任何包含 RF 校准信息的 PAC 直接禁止刷写，避免损坏模组射频参数
- **NV 写入限制**：非 Erase / NV 写入将被默认阻断

## 20. 常见问题排查

### 20.1 启动失败

| 现象 | 排查方向 |
|---|---|
| 双击 `.exe` 没反应 | 检查 WebView2 Runtime 是否安装；查看 `%LOCALAPPDATA%\Modem Cat\logs\startup.log` |
| 提示缺少 DLL | 确认 `vcruntime140.dll`（x86）在 `dist/` 根目录 |
| macOS 提示「无法验证开发者」 | 系统设置 → 隐私与安全性 → 仍要打开 |

### 20.2 连接问题

| 现象 | 排查方向 |
|---|---|
| 找不到串口 | 确认模组已插入且驱动正常；尝试刷新端口列表 |
| 连接失败 | 确认串口未被其他程序占用；尝试手动选择端口 |
| 连接后无响应 | 检查模组供电；尝试降低波特率；查看 `startup.log` |
| WebSocket 连接失败 | 确认网关支持 WebSocket；检查用户名 / 密码是否正确 |

### 20.3 AT 调试问题

| 现象 | 排查方向 |
|---|---|
| 发送命令无响应 | 先点击状态页「刷新」确认模组在线；检查 AT 口是否 Mulitplex 复用 |
| ICCID 显示 `--` | SIM 卡未就绪时正常跳过；SIM PIN 解锁后再查 |
| 固件下载提示"未找到 sidecar" | 确认 `r26-cli-x86_64-pc-windows-msvc.exe` 和 `vcruntime140.dll` 与 `modem-cat.exe` 同目录 |

### 20.4 ADB / SSH 调试问题

| 现象 | 排查方向 |
|---|---|
| ADB 调试试页不可见 | 仅 Windows 显示；请确认运行在 Windows 上 |
| ADB 连接失败 | 确认模组已启用 ADB；检查 ADB 组件文件完整性 |
| SSH 连接失败 | 确认设备 IP 正确；检查用户名 / 密码；确认设备已开启 SSH 服务 |

### 20.5 配置丢失

- 界面语言 / 主题 / 缩放设置由浏览器 `localStorage` 保存，不受重启影响
- MQTT 状态以 Modem Cat 后端 `AppState` 为准，非 `localStorage`
- Modem / APN / 频段等配置保存在模组端，Modem Cat 仅实时读取
