# APN Modal Popup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert APN editing from inline form to centered floating modal popup, add a "新增 APN" button on the main page.

**Architecture:** Pure CSS overlay + JS toggle approach. A hidden modal overlay div is added to the DOM, toggled via JS `display`. The existing inline form is removed. A new "新增 APN" button is added below the APN list. Both add and edit flows open the same modal popup.

**Tech Stack:** HTML/CSS/JS (single-file frontend, no framework), Tauri IPC (unchanged)

### Task 3: Update JavaScript Functions for Modal

**Files:**

- [ ] **Step 1: Update `renderApnList()` empty state message**

In `renderApnList()` (line 1758), change the empty state message from "暂无 APN，请在下方添加" to "暂无 APN，请点击下方按钮添加":

```js
    function renderApnList() {
      const list = document.getElementById('apnList');
      if (apnData.length === 0) {
        list.innerHTML = '<div style="color:var(--text-muted);font-size:12px;padding:8px 0;">暂无 APN，请点击下方按钮添加</div>';
        return;
      }
      list.innerHTML = apnData.map((a, i) => `
        <div class="apn-item ${editingApnIdx === i ? 'selected' : ''}" onclick="editApn(${i})">
          <div class="apn-item-info">
            <div class="apn-item-name">${a.name}</div>
            <div class="apn-item-meta">${a.ip.toUpperCase()} · 鉴权: ${a.auth.toUpperCase()}${a.user ? ' · 用户: ' + a.user : ''}</div>
          </div>
          ${a.active ? '<span class="apn-item-active">当前</span>' : `<button class="btn btn-secondary btn-sm" onclick="event.stopPropagation();setActiveApn(${i})">激活</button>`}
          <button class="btn btn-secondary btn-sm" onclick="event.stopPropagation();deleteApn(${i})">删除</button>
        </div>
      `).join('');
    }
```

- [ ] **Step 2: Replace `editApn()`, `cancelApnEdit()` with modal-based functions**

Replace the existing `editApn(i)` (lines 1773-1784) and `cancelApnEdit()` (lines 1786-1794) with:

```js
    function openApnModal() {
      editingApnIdx = -1;
      ['apnName','apnUser','apnPass'].forEach(id => document.getElementById(id).value = '');
      document.getElementById('apnAuth').value = 'none';
      document.getElementById('apnIp').value = 'ipv4';
      document.getElementById('apnModalTitle').textContent = '新增 APN';
      document.getElementById('apnModalOverlay').classList.add('active');
      renderApnList();
    }

    function editApn(i) {
      editingApnIdx = i;
      const a = apnData[i];
      document.getElementById('apnName').value = a.name;
      document.getElementById('apnUser').value = a.user;
      document.getElementById('apnPass').value = a.pass;
      document.getElementById('apnAuth').value = a.auth;
      document.getElementById('apnIp').value = a.ip;
      document.getElementById('apnModalTitle').textContent = '编辑 APN';
      document.getElementById('apnModalOverlay').classList.add('active');
      renderApnList();
    }

    function closeApnModal() {
      document.getElementById('apnModalOverlay').classList.remove('active');
      editingApnIdx = -1;
      renderApnList();
    }
```

Note: `cancelApnEdit()` is replaced by `closeApnModal()` and `openApnModal()`. The `cancelApnEdit` function is removed entirely.

- [ ] **Step 3: Update `saveApn()` to close modal on success**

Replace the existing `saveApn()` (lines 1796-1822) with:

```js
    async function saveApn() {
      const name = document.getElementById('apnName').value.trim();
      if (!name) { alert('请输入 APN 名称'); return; }
      const authMap = { none: 0, pap: 1, chap: 2 };
      const ipTypeMap = { ipv4: 1, ipv6: 2, ipv4v6: 3 };
      const auth = document.getElementById('apnAuth').value;
      const ipType = document.getElementById('apnIp').value;
      const user = document.getElementById('apnUser').value.trim();
      const pass = document.getElementById('apnPass').value;

      try {
        const cid = editingApnIdx >= 0 ? apnData[editingApnIdx].cid : (apnData.length + 1);
        await invoke('set_apn_config', {
          cid,
          contextType: ipTypeMap[ipType] || 1,
          apn: name,
          username: user,
          password: pass,
          authType: authMap[auth] || 0,
        });
        addTerminalLine(`[APN] 已保存: ${name}`, 'ok');
        closeApnModal();
        await refreshApnList();
      } catch (e) {
        addTerminalLine('[APN] 保存失败: ' + e, 'err');
      }
    }
```

The key change: `cancelApnEdit()` is replaced with `closeApnModal()` in the success path.
